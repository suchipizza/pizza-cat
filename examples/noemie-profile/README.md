# Noémie’s profile scene

An original black-and-white husky, the black cat, and five independent flights of pizza, maki, and nigiri. This personal scene builds on the reusable husky/cat example.

```sh
npm run generate -- --config examples/noemie-profile/profile.config.ts --out /tmp/noemie-profile
```

The live profile is [github.com/suchipizza](https://github.com/suchipizza). Its profile repository is an independent copy of this template: [suchipizza/suchipizza](https://github.com/suchipizza/suchipizza).
